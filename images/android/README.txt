รูปสินค้า Android วางในโฟลเดอร์นี้

ชื่อไฟล์ = เลขในคอลัมน์ image link (คอลัมน์ C) ของชีต Android
ตัวอย่าง  image link = 161  ->  161.jpg

นามสกุลที่รองรับ: .jpg (ใช้เป็นหลัก)  .png  .webp   ใช้ตัวพิมพ์เล็กทั้งหมด
ถ้าคอลัมน์ image link ว่าง เว็บจะใช้ชื่อรุ่นแทน (ตัวพิมพ์เล็ก คั่นด้วย -)
ถ้าไม่พบรูป เว็บจะแสดงรูปแทนที่ และ F12 > Console จะบอกชื่อไฟล์ที่ต้องการ
